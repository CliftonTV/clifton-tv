# App Assets

Create the following image assets for the app:

## Required Assets

### icon.png
- Size: 1024x1024 pixels
- Format: PNG (no transparency for iOS App Store)
- Content: App icon (airplane with weather elements)
- Background: #d44000 (brand orange)

### splash.png
- Size: 1284x2778 pixels (iPhone 14 Pro Max)
- Format: PNG
- Content: Centered logo or text
- Background: #d44000 (brand orange)

### adaptive-icon.png (Android)
- Size: 1024x1024 pixels
- Format: PNG with transparency
- Content: Foreground icon only

### favicon.png (Web)
- Size: 48x48 pixels
- Format: PNG

## Quick Start

You can generate placeholder assets using:
```bash
npx expo-optimize
```

Or use online tools like:
- https://easyappicon.com
- https://appicon.co
- https://makeappicon.com
